Project created and designed by me for sAnIty: an AI-assisted e-health platform for continuous psychological support with clinical supervision by licensed psychologists. It includes UI/UX design, Business Model, and a technical prototype developed using Lovable, Azure OpenAI (GPT-4o), RAG on validated CBT protocols, and compliance with GDPR and the EU AI Act.
